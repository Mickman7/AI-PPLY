# AI-PPLY
AI-PPLY is a fullstack web application that helps job seekers optimise their resumes for Applicant Tracking Systems (ATS) and specific job postings.

## Technologies
- React
- TypeScript
- Tailwind CSS
- Python (FastAPI)
- ChatGPT (OpenAI API)
- Docker

## Features
- Upload a Resume and Job Description
- Get a Score of How Much your Resume Matches Job Description
- Get Positive and Negative Feedback on your Resumes Tone, Content, Structure and Skills
- Save and View Past Job Analyses
- Create a profile

## The Process
To start my journey in understanding AI i started with a simple project that uses an LLM in order to analyse my resume with a job decription of my choosing. A user can either access the resume analysis feature without creating an account which doesn't give you the option to save previous analyses or they can create an account and have access to all features. When signed up navigate to upload page and provide a resume and job description and click the analyse button. You will then be shown your results.

### Running the Project
1. Clone the repository
2. Install depenancies: npm install
3. Move into frontend folder and run development server: npm run dev
4. Move into backend folder and run server: python3 -m uvicorn backend.main:app --reload
5. Open: http://localhost:8000 in your browser
